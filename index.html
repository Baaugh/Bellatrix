What's new in 3.0.3

The biggest Bellatrix update yet.

⇄

Multi-account switcher

Save your accounts once and switch between them in one click. Bellatrix closes League, signs you out of the Riot Client, logs into the account you picked, and offers to launch League. No restart needed.

🔒

Stays on your PC

Saved logins and sessions are stored only on your own computer. Nothing is uploaded or sent anywhere.

✦

Working auto-updater

No more stray terminal window that does nothing. Bellatrix now downloads the new version from GitHub, installs it, and reopens itself.

☾

Redesigned Command Center

The dashboard has a new witchy look: darker, cleaner, and easier to read at a glance.

⚡

Lighter launches

Opening League through Bellatrix now uses fewer resources, so your PC isn't fighting itself before champ select.

🛡

Security hardening

A full security pass across the app, tightening how Bellatrix handles your data and talks to the client.

Changelog

Version 3.0.3

New
  • Account switcher with saved credentials or captured sessions
  • "Capture Session" button for accounts that use Riot's "Stay signed in"
  • Option to launch League right after switching accounts
  • Redesigned Command Center UI
Fixed
  • Auto-updater found new versions but never installed them
  • App didn't reopen after an update
  • Wrong account showed as "Active" after switching
  • High resource use when launching League from Bellatrix
  • Various smaller bug fixes
Removed
  • VOD recorder. It wasn't producing recordings reliably, so it's been taken out completely.

Install or update

Takes about a minute.

Download the latest release from the GitHub Releases page.

Run the installer. If you already have Bellatrix, it installs over your current version.

Open Bellatrix and add your accounts in the Accounts tab to start switching.

Found a bug? Open an issue on the GitHub Issues page.
