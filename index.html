Riot Games Developer & Vanguard Policy Verification 100% Out-of-Process

Safe by Architecture: 100% Out-of-Process

LoL Companion operates strictly in compliance with Riot Games Third-Party Developer Policies. The application runs completely outside the game process, reading only official local endpoints without ever modifying or hooking game memory.

✓ Zero Memory Editing

No ReadProcessMemory or WriteProcessMemory. Zero memory hooks.

✓ Zero DLL Injection

No DirectX hooking or process injection. Standard transparent Windows OS overlay (WS_EX_TRANSPARENT).

✓ Fog of War Protected

Only reads official, sanctioned local APIs: local LCU port and Live Client Data (127.0.0.1:2999).

✓ Zero Automation

Strictly visual telemetry. Zero macro clicking, zero ward timers in fog, zero spell queueing.
