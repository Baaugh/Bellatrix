Riot Games Developer & Vanguard Policy Verification

Welcome Riot Reviewers! This section provides full technical transparency into how LoL Companion complies strictly with Riot Games Third-Party Developer Policies and Vanguard Anti-Cheat requirements.

✓

Zero Game Memory Modification

No ReadProcessMemory or WriteProcessMemory. The app never attaches to, modifies, or inspects the memory space of League of Legends.exe.

✓

Zero DLL Injection / DirectX Hooks

100% out-of-process architecture. The in-game HUD is a standard transparent Windows OS overlay (WS_EX_TRANSPARENT).

✓

Strict Fog of War Integrity

Only reads publicly accessible, sanctioned local APIs: League Client Update (LCU) lockfile and Live Client Data API (https://127.0.0.1:2999/liveclientdata).

✓

No Input Automation or Macros

Strictly visual telemetry and personal benchmark guidance. Zero automated clicking, zero ward timers in fog of war, zero spell queueing.
